# microqr

A tiny QR code scanner for Android 5 and later, without Google Play services. It opens on the camera and shows what the code holds, with buttons to open, copy or scan again.

Get the APK from [Releases](https://github.com/Synaelle/microqr/releases) or build it with `./gradlew assembleRelease`.

Icons from [Lucide](https://lucide.dev) (ISC), decoding by [ZXing](https://github.com/zxing/zxing) (Apache 2.0). Released under the MIT license.
